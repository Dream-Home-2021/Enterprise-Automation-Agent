核心问题
只有"读"没有"写"。 整个记忆系统的现状是：


能做的：
  ✅ Redis 检查点 → 短期记忆（对话上下文）
  ✅ 读 PostgreSQL 画像 → 注入 supervisor 的 system prompt
  ✅ 会话 CRUD + 历史消息恢复

做不到的（代码写了但没接进去）：
  ❌ 对话结束后提炼偏好
  ❌ 生成对话摘要存回数据库
  ❌ 更新用户画像
  ❌ 向量化存储（RAG）
  ❌ 根据历史记忆做个性化回复
profile.py + extract.py + long_term.py::save_conversation_memory 构成了一条完整的**"对话 → 提炼 → 偏好提取 → 摘要生成 → 画像更新 → 向量化存储"**管线，但没有任何地方触发它。
